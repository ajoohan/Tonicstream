# Tonicstream — 영상 저장 확장 프로그램 (Edge / Chrome)

브라우저에서 재생 중인 영상(유튜브 쇼츠, 인스타그램 릴스, 틱톡, Vimeo, 일반 스트리밍 영상)을 **MP4 파일로 저장**하는 확장 프로그램입니다.

## 사이트별 저장 방식

| 사이트 | 방식 | 걸리는 시간 |
|---|---|---|
| 유튜브 · 유튜브 쇼츠 | 화면 녹화 → MP4 | 영상 길이만큼 |
| 인스타그램 릴스 | 화면 녹화 → MP4 | 영상 길이만큼 |
| 틱톡 | **원본 파일 다운로드** → MP4 (원본 화질) | 즉시 |
| Vimeo · 일반 사이트 | 화면 녹화 또는 원본 다운로드 | — |

> 틱톡은 영상을 다른 서버(CDN)에서 불러오기 때문에 브라우저가 녹화를 막습니다. 대신 원본 파일을 바로 받도록 자동으로 버튼이 바뀝니다.
> 유튜브 광고가 재생 중일 때는 녹화가 시작되지 않습니다. 광고가 끝난 뒤 눌러주세요.

## 저장 방식 2가지

| 방식 | 언제 쓰나 | 특징 |
|---|---|---|
| **화면 녹화 저장** | 유튜브·쇼츠·릴스·틱톡·Vimeo 등 대부분 (다른 사이트에 퍼가기된 영상 포함) | 재생되는 영상을 그대로 녹화해 MP4로 저장. 실제 재생 시간만큼 걸림 (30초 쇼츠 = 30초) |
| **바로 다운로드** | 사이트가 원본 MP4 파일을 그대로 보내줄 때 (틱톡, 일반 웹사이트 등) | 원본 화질 그대로 즉시 저장 |

- **처음부터 끝까지 녹화**: 영상을 0초로 되돌려 끝까지 녹화하고 자동으로 저장합니다. 반복 재생되는 쇼츠·릴스·틱톡도 한 바퀴만 녹화하고 멈춥니다.
- **지금부터 녹화**: 원하는 지점부터 녹화를 시작하고 "정지 후 저장"을 누르면 저장됩니다. 라이브 방송에 적합합니다.
- 녹화 중에 팝업을 닫아도 녹화는 계속됩니다. 영상을 일시정지하면 녹화도 일시정지됩니다.

## 설치 방법 (개발자 모드)

1. 이 저장소를 내려받습니다 (Code → Download ZIP 후 압축 해제).
2. **Edge**: 주소창에 `edge://extensions` 입력 → 왼쪽 아래 **개발자 모드** 켜기
   **Chrome**: `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
3. **압축 풀린 항목 로드(Load unpacked)** → `extension` 폴더 선택
4. 툴바의 퍼즐 아이콘에서 확장 프로그램을 고정하면 편합니다.

## 사용 방법

1. 저장할 영상 페이지를 열고 영상을 **재생**합니다.
2. 확장 프로그램 아이콘 클릭 → 원하는 버튼 클릭.
3. 파일은 브라우저 기본 다운로드 폴더에 `페이지 제목.mp4`로 저장됩니다.

## 알아둘 점 / 한계

- **녹화 화질 = 재생 화질**입니다. 유튜브는 톱니바퀴에서 화질을 높게 설정한 뒤 녹화하세요.
- 녹화 중에는 탭을 닫거나 다른 영상으로 넘기지 마세요 (다른 탭으로 이동하는 건 괜찮습니다).
- 녹화본의 소리는 Opus 코덱입니다. 대부분의 플레이어·편집툴(Premiere, CapCut, VLC, 윈도우 미디어 플레이어)에서 재생되지만, 일부 맥 기본 앱에서 소리가 안 나오면 VLC를 쓰거나 변환하세요.
- **넷플릭스·디즈니+·티빙 등 DRM 보호 영상은 저장되지 않습니다** (브라우저가 막아 검은 화면만 남습니다). 이는 의도된 동작입니다.
- 유튜브·Vimeo 원본은 조각 단위로 스트리밍되므로 "바로 다운로드"에 나타나지 않습니다 → 녹화 방식을 사용하세요.

## 저작권 / 배포 관련 주의

- 본인 소유이거나 저작권자에게 허락받은 영상, 또는 법이 허용하는 범위(내부 참고·리서치 등)에서만 사용하세요. 다운로드한 영상을 재업로드·광고 소재로 쓰는 것은 저작권 침해가 될 수 있습니다.
- 유튜브·틱톡 등 각 플랫폼 이용약관은 다운로드를 제한할 수 있습니다.
- **Chrome 웹 스토어는 유튜브 다운로드 기능이 있는 확장을 승인하지 않습니다.** 사내 배포는 위의 "압축 풀린 항목 로드" 방식이나 Edge 정책 배포를 권장합니다.

## 파일 구성

```
extension/
├─ manifest.json   확장 설정 (Manifest V3)
├─ background.js   네트워크에서 원본 영상 파일 주소 감지, 다운로드 실행
├─ content.js      페이지 속 영상 찾기 + 녹화(MediaRecorder) 후 MP4 저장
├─ offscreen.html/js 틱톡 원본 파일을 받아 저장하는 숨겨진 페이지
├─ popup.html/css/js  아이콘 클릭 시 보이는 화면
```
