자동 업데이트 설정 (IT 담당자용)

회사 PC의 Edge·Chrome에 정책으로 설치하면, 새 버전이 나올 때 브라우저가 알아서 업데이트합니다. 직원이 ZIP을 받아 덮어쓸 필요가 없습니다.

확장 ID
feeaeacfnjjglkpblombicpdecfdghfp

업데이트 주소
https://stream.plustonic.com/updates.xml

정책에 넣을 값 (한 줄)
feeaeacfnjjglkpblombicpdecfdghfp;https://stream.plustonic.com/updates.xml

순서 한눈에 보기

  1. 서명 열쇠 등록 (한 번만): GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret. 이름 CRX_PRIVATE_KEY, 값은 열쇠 파일 내용 전체. 등록 후 다음 배포부터 updates.xml이 열립니다(지금 404면 아직 등록 전).
  2. PC가 회사 관리 대상인지 확인: 명령 프롬프트에서 dsregcmd /status → AzureAdJoined : YES 또는 DomainJoined : YES이면 관리 대상입니다. 둘 다 NO인 PC(개인 PC, 도메인 미가입)는 Edge·Chrome이 스토어 밖 확장의 강제 설치를 막으므로, 지금처럼 ZIP으로 설치·업데이트합니다.
  3. 정책 넣기: 직원이 많으면 아래 그룹 정책(GPO)이나 Intune으로 한 번에, 몇 대뿐이면 각 PC에서 설치 정책 파일(.reg)을 관리자 권한으로 실행합니다. Edge와 Chrome 둘 다 들어갑니다.
  4. 브라우저 다시 시작 후 edge://extensions에서 Tonicstream이 “조직에서 설치함”으로 보이면 끝입니다.
  5. 기존 ZIP 설치본 정리: 예전 확장의 보관함에서 백업 → 새 확장의 보관함에서 가져오기 → 예전 확장 제거.

이미 다른 확장을 강제 설치 정책으로 쓰고 있다면 .reg 파일의 이름 "1"이 겹칠 수 있습니다. 그때는 빈 번호(예: "2")로 바꿔 넣으세요. 정책을 없애려면 제거 정책 파일(.reg)을 실행합니다.

1. Edge (Windows · 그룹 정책 또는 Intune)

정책 ExtensionInstallForcelist(강제로 설치되는 확장 목록)에 위의 한 줄을 추가합니다.

그룹 정책 편집기: 컴퓨터 구성 → 관리 템플릿 → Microsoft Edge → 확장 → “강제 설치된 확장 목록 제어”

레지스트리로 넣을 때:

HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Edge\ExtensionInstallForcelist
  이름: 1   (문자열 값)
  값:   feeaeacfnjjglkpblombicpdecfdghfp;https://stream.plustonic.com/updates.xml

2. Chrome (Windows · 그룹 정책 또는 Chrome 브라우저 클라우드 관리)

같은 정책 ExtensionInstallForcelist에 같은 값을 넣습니다.

HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Google\Chrome\ExtensionInstallForcelist
  이름: 1   (문자열 값)
  값:   feeaeacfnjjglkpblombicpdecfdghfp;https://stream.plustonic.com/updates.xml

3. 확인

edge://policy 또는 chrome://policy에서 정책이 보이는지, edge://extensions에서 Tonicstream이 “조직에서 설치함”으로 나오는지 확인합니다. 업데이트는 브라우저가 몇 시간마다 확인하며, 확장 화면의 “업데이트” 버튼으로 바로 받을 수도 있습니다.

알아 둘 점

  • 회사 관리 PC가 아니면(dsregcmd에서 모두 NO): 이 정책은 적용되지 않습니다. 대신 확장 폴더의 Tonicstream-update.cmd(업데이트 도우미)로 업데이트합니다. 새 버전 알림이 뜨면 더블클릭 → 팝업에서 [지금 적용]. 예약 작업이나 백그라운드 실행 없이, 누를 때만 동작합니다.
  • Windows에서 스토어 밖 확장을 강제 설치하려면 PC가 회사 도메인(Active Directory)에 가입돼 있거나 Intune·Chrome 클라우드 관리로 관리돼야 합니다. 개인 PC에는 적용되지 않습니다.
  • Mac은 MDM(기기 관리)으로 같은 정책을 배포합니다.
  • 이미 ZIP으로 설치한 직원은 정책 설치본과 따로 두 개가 생깁니다. 먼저 기존 확장의 보관함 → 백업으로 기록을 저장하고, 새 확장의 보관함 → 가져오기로 옮긴 뒤 ZIP 설치본을 지우세요.
  • 확장 ID는 서명 열쇠로 정해집니다. 열쇠를 바꾸면 ID가 바뀌어 다시 설정해야 하므로, 열쇠는 안전하게 보관합니다.
