세 가지 방법으로, 거의 모든 영상을

사이트에 맞는 방법을 확장 프로그램이 알아서 보여줍니다.

01

영상 녹화

재생 중인 영상을 그대로 MP4로 저장합니다. ‘처음부터 끝까지’를 누르면 무한 반복되는 쇼츠도 딱 한 바퀴만 녹화하고 자동 저장돼요. 유튜브 광고 구간은 알아서 건너뜁니다.

02

원본 다운로드

사이트가 원본 파일을 보내주는 경우(틱톡 등) 녹화 없이 원본 화질 그대로 즉시 저장합니다. 기다릴 필요가 없어요.

03

탭 전체 녹화

위 방법이 안 통하는 사이트라면 탭 화면과 소리를 통째로 녹화하세요. 영상을 전체화면으로 두면 영상만 깔끔하게 담깁니다. 녹화 중에도 다른 탭에서 일할 수 있어요.

1분이면 설치 끝

스토어를 거치지 않는 ‘개발자 모드’ 설치 방식입니다.

  1. ZIP 파일 다운로드 후 원하는 폴더에 압축을 풀어주세요.
  2. 주소창에 edge://extensions
    (크롬은 chrome://extensions) 입력
  3. 개발자 모드를 켜고 압축 풀린 항목 로드 클릭
  4. 압축을 푼 폴더를 선택하면 완료! 퍼즐 아이콘에서 고정해 두면 편해요.

💡 단축키 Alt + Shift + V 로 언제든 저장 창을 열 수 있어요. 압축 푼 폴더는 지우지 마세요.

자주 묻는 질문

 

화질은 어떻게 되나요?

녹화 방식은 재생 중인 화질 그대로 저장됩니다. 유튜브는 플레이어 톱니바퀴에서 화질을 높게 설정한 뒤 녹화하세요. 원본 다운로드는 원본 화질 그대로입니다.

30초 쇼츠는 저장에 얼마나 걸리나요?

녹화 방식은 실제 재생 시간만큼 걸립니다(30초 영상 = 약 30초). 녹화 중에 창을 닫거나 다른 탭으로 이동해도 계속 녹화됩니다. 단, 영상이 있는 탭은 닫지 마세요.

음소거된 릴스도 소리가 저장되나요?

네. 화면에서 음소거 상태여도 영상 원래 소리가 함께 저장됩니다.

맥에서 소리가 안 나와요.

녹화 파일의 소리는 Opus 코덱이라 일부 맥 기본 앱에서 재생되지 않을 수 있습니다. VLC, 프리미어, CapCut 등에서는 정상 재생됩니다.

넷플릭스·티빙 영상은 왜 안 되나요?

유료 OTT 영상은 저작권 보호 기술(DRM)이 적용되어 있어 브라우저가 녹화를 막습니다. Tonicstream은 이 보호 기술을 우회하지 않으며, 앞으로도 지원하지 않습니다.

내 시청 기록이나 영상이 어딘가로 전송되나요?

아니요. 모든 작업은 내 브라우저 안에서만 이뤄지고, 파일은 내 컴퓨터의 다운로드 폴더에 바로 저장됩니다. 별도 서버도, 회원가입도, 데이터 수집도 없습니다. 개인정보 처리방침

왜 크롬 웹 스토어에 없나요?

크롬 웹 스토어는 유튜브 영상 저장 기능이 있는 확장 프로그램을 등록받지 않습니다. 그래서 이 페이지에서 직접 받아 설치하는 방식으로 제공합니다.

바르게 사용해 주세요

  • 본인이 만든 영상, 권리자에게 허락받은 영상, 또는 내부 참고·리서치 용도로만 사용해 주세요.
  • 저장한 영상을 재업로드하거나 광고·상업 소재로 사용하면 저작권 침해가 될 수 있습니다.
  • 각 플랫폼의 이용약관을 확인해 주세요. 사용에 따른 책임은 사용자에게 있습니다.
