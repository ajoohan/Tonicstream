Edge · Chrome 확장 프로그램 · v0.14.5

상황별로 이렇게 쓰세요

모두 영상 페이지에서 툴바의 Tonicstream 아이콘을 눌러 시작합니다.

1

영상 녹화

쇼츠·릴스·틱톡을 보다가 “이거 저장해 두자” 싶을 때

  1. 영상 페이지에서 툴바의 Tonicstream 아이콘(또는 Alt+Shift+V)
  2. 처음부터 끝까지 녹화를 누르면 처음으로 돌아가 끝까지 녹화하고 저장
  3. 녹화하는 동안 페이지 위의 정지 바로 언제든 멈추고 저장
2

구간 녹화

긴 영상에서 필요한 장면만 잘라 두고 싶을 때

  1. 구간 녹화를 누르면 시작·끝 시간 칸이 열림
  2. 분:초로 적고 이 구간 녹화
  3. 그 구간만 MP4로 저장
3

장면 · 페이지 캡처

썸네일·색감·컷 구성을 레퍼런스로 남기고 싶을 때

  1. 장면 캡처: 지금 보이는 장면을 PNG 한 장으로
  2. 콘티 시트: 영상 전체에서 장면 12개를 뽑아 한 장짜리 그리드로
  3. 페이지 전체 캡처: 상세페이지·랜딩페이지를 위에서 아래까지 한 장으로
4

탭 · 화면 녹화

위 방법이 안 되는 사이트, 라이브, 웹이 아닌 프로그램 화면까지

  1. 탭 녹화: 이 탭의 화면과 소리를 그대로 (어떤 사이트든)
  2. 화면 녹화: 모니터 전체나 다른 프로그램 창, 마이크 소리도 함께
  3. 웹캠 창을 띄워 얼굴을 함께 담거나, 중간에 일시정지
5

원본 · 스트리밍 다운로드

녹화보다 빠르게, 원본 화질 그대로 받고 싶을 때

  1. 바로 다운로드에 원본 파일이나 스트리밍 영상이 잡히면 화질을 골라 받기
  2. 받는 중에도 다른 영상을 더하면 목록에 쌓여 차례로 받음
  3. 다른 페이지로 옮기거나 팝업을 닫아도 계속 받음. 생방송도 OK
6

레퍼런스 보관함

저장한 영상을 캠페인별로 모아 팀과 나누고 싶을 때

  1. 저장할 때마다 미리보기·원본 주소·계정·게시일이 자동 기록
  2. 보드·별점·메모·태그로 정리하고 검색
  3. HTML·CSV 내보내기로 팀에 공유, 백업으로 다른 PC에 옮기기

설치

  1. ZIP을 다운로드해 Tonicstream 폴더를 새로 만들어 그 안에 압축 풀기 (지우지 않을 곳에)
  2. edge://extensions 열기
  3. 개발자 모드 켜기
  4. 압축 풀린 항목 로드 → 폴더 선택

업데이트

새 버전이 나오면 팝업 맨 위에 알림이 뜹니다. 두 번만 누르면 됩니다. 보관함 기록과 설정은 그대로 남습니다.

  1. 바탕화면의 Tonicstream 업데이트(또는 확장 폴더의 Tonicstream-update.cmd)를 더블클릭. 검은 창에서 새 버전을 받아 폴더를 바꿉니다
  2. Tonicstream 아이콘을 눌러 맨 위의 지금 적용 누르기

처음 한 번 실행할 때 바탕화면 바로가기를 만들지 물어봅니다. Windows가 “PC 보호” 창을 띄우면 추가 정보 → 실행을 누르세요. 0.13.1보다 오래된 버전은 폴더에 업데이트 파일이 없으니, 한 번만 새 ZIP을 받아 처음 설치한 같은 폴더에 덮어쓰고 edge://extensions에서 새로 고침(↻)을 눌러 주세요.
