개인정보 처리방침

시행일: 2026년 11월 24일 · 적용 대상: Tonicstream 브라우저 확장 프로그램

1. 수집하는 정보

Tonicstream은 이름, 이메일, 시청 기록, 방문한 사이트 등 어떠한 개인정보도 수집하거나 외부로 전송하지 않습니다. 회원가입이 없고, 사용자 데이터를 받는 서버도 없으며, 분석·광고 도구도 사용하지 않습니다. 확장이 스스로 인터넷에 접속하는 경우는 세 가지뿐입니다. 새 버전 확인(3번), 사용자가 저장을 누른 영상 파일 받기, 그리고 확장 창을 열었을 때 그 페이지에 적혀 있는 영상 주소가 실제 영상 파일인지 해당 서버에 확인하는 요청입니다. 이 확인 요청은 사용자가 보고 있는 페이지의 영상 주소로만 보내며, 다른 정보는 담지 않습니다.

2. 브라우저 안에서만 처리되는 정보

  • 현재 탭에서 재생 중인 영상의 주소와 크기: 저장 버튼을 보여주기 위해 브라우저 메모리에 잠시 보관하며, 탭을 닫거나 브라우저를 종료하면 삭제됩니다.
  • 보관함 기록(저장한 영상의 제목, 원본 페이지 주소와 사이트 이름, 저장 날짜, 저장 방법, 저장된 파일 이름과 하위 폴더, 작은 미리보기 그림, 직접 정한 보드·별점·메모·태그, 그리고 저장한 페이지에 공개적으로 적혀 있는 게시물 정보인 계정 이름·게시일·설명·해시태그·조회수·좋아요 수)과 저장 설정: 사용자의 브라우저에만 저장되며 외부로 전송되지 않습니다. 보관함에서 언제든 지울 수 있고, 저장 설정에서 기록을 끌 수 있습니다. ‘백업’을 누르면 사용자가 고른 위치에 파일로 저장되며, 이 파일도 외부로 전송되지 않습니다. 시크릿 창에서 저장한 것은 기록하지 않습니다.
  • 녹화·다운로드한 영상: 사용자의 컴퓨터 다운로드 폴더에 바로 저장되며, 다른 곳으로 전송되지 않습니다.

3. 새 버전 확인

ZIP으로 설치한 경우, 확장 창을 열 때 12시간에 한 번 정도 stream.plustonic.com/version.json 파일을 읽어 새 버전이 있는지 확인합니다. 이때 사용자 정보는 보내지 않으며, 일반적인 웹 접속과 같이 접속 기록(IP 주소 등)만 호스팅 서버(GitHub Pages)에 남을 수 있습니다. 회사 PC에 정책으로 설치한 경우에는 브라우저가 몇 시간마다 stream.plustonic.com/updates.xml을 읽어 스스로 업데이트하며, 이때도 사용자 정보는 보내지 않습니다.

4. 권한을 사용하는 이유

  • 모든 사이트 접근, 네트워크 요청 보기: 페이지 속 영상과 원본 영상 파일을 찾기 위해
  • 다운로드: 영상을 파일로 저장하기 위해
  • 탭 캡처: 사용자가 ‘탭 녹화’를 눌렀을 때만 해당 탭 화면과 소리를 녹화하기 위해
  • 화면 녹화: 사용자가 ‘화면 녹화’에서 직접 고른 화면(모니터·창·탭)만 녹화합니다. 마이크는 사용자가 ‘마이크 소리 함께 녹음’을 켰을 때만, 웹캠은 사용자가 ‘웹캠 창 띄우기’를 눌렀을 때만 사용합니다. 웹캠 화면은 사용자 화면에만 표시되며 따로 전송하거나 저장하지 않습니다. 녹화 파일은 컴퓨터에만 저장됩니다.
  • 네트워크 요청 수정: 틱톡 원본 영상이나 스트리밍 영상을 받을 때, 영상 서버가 확인하는 요청 정보(Referer·Origin)에 사용자가 보고 있던 페이지의 주소를 붙이기 위해. 확장이 직접 보내는 요청에만 적용되며, 사용자가 보는 페이지의 요청과 새 버전 확인 요청은 바꾸지 않습니다
  • 마우스 오른쪽 메뉴: 영상이나 페이지에서 오른쪽 버튼을 눌렀을 때 저장·캡처 메뉴를 보여 주기 위해. 사용자가 메뉴를 고를 때만 동작합니다
  • 저장 공간 제한 없음: 큰 스트리밍 영상을 받을 때 조각을 브라우저의 확장 전용 저장 공간에 잠시 모았다가 한 파일로 저장하기 위해. 저장이 끝나면 바로 지웁니다
