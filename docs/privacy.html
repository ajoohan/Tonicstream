3. 권한을 사용하는 이유

  • 다운로드: 영상을 파일로 저장하기 위해

  • 네트워크 요청 수정: 틱톡 원본 영상을 받을 때 필요한 요청 정보를 붙이기 위해 (틱톡 영상 서버에 한함)
